# Appium Mobile Practice

A Mobile Automation practice repository built using Appium, Java, TestNG, and Maven for Android & iOS application testing.

This repository contains Appium examples, mobile gestures, device interactions, and reusable automation utilities commonly used in Mobile Automation Testing.

---

## Topics Covered

###  Appium Basics
- Appium Setup
- Desired Capabilities
- Driver Initialization
- Emulator & Real Device Setup

###  Mobile Element Handling
- Locators
- Click Actions
- SendKeys
- Element Validation

###  Mobile Gestures
- Swipe
- Scroll
- Tap
- Long Press
- Drag & Drop

###  Android Automation
- Native App Testing
- Hybrid App Testing

###  iOS Automation
- iOS Device Handling
- iOS Element Interaction

###  TestNG Integration
- Assertions
- Parallel Execution
- Test Execution
